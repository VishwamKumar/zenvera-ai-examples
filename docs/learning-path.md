# Learning path

1. **Chat** — `IChatClient`, secrets, streaming, structured output.
2. **Manual RAG** — embeddings and cosine search by hand.
3. **MEDI RAG** — the same loop with `Microsoft.Extensions.DataIngestion`.
4. **ChatWeb** — persistent topology (Aspire + Qdrant) with the same grounded chat. Switch `Ai:Provider` instead of opening a second solution.
5. **MCP stdio**, then **MCP orders** — tools for Copilot/agents.
6. **Agent** — Microsoft Agent Framework on top of `IChatClient`.
7. **Applied** — add semantic search and grounded answers to an existing catalog API.
